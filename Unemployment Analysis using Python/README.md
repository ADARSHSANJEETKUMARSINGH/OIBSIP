# Unemployment Analysis using Python

## 📌 Project Overview

This project focuses on analyzing unemployment trends in India using Python. The goal is to understand how unemployment varies across different states, regions, and time periods, especially during the Covid-19 pandemic.

---

## 📊 Dataset

The project uses two datasets:

* Unemployment in India
* Unemployment Rate up to 11/2020

These datasets include information such as:

* Region (State)
* Date
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)
* Area (Rural/Urban)

---

## 🛠️ Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly

---

## 🔍 Key Steps Performed

1. Data Loading
2. Data Cleaning (handling missing values, duplicates, column formatting)
3. Exploratory Data Analysis (EDA)
4. Visualization (bar plots, boxplots, histograms, scatter plots)
5. Time Series Analysis (trend over time using Plotly)

---

## 📈 Key Insights

* Most states have unemployment rates in the lower range, but some show extreme spikes.
* Significant variation exists between different regions.
* Covid-19 had a noticeable impact on unemployment trends.
* Labour participation varies across regions, indicating workforce differences.

---

## 🎯 Conclusion

This project demonstrates how data analysis can be used to extract meaningful insights from real-world datasets. It highlights regional differences and temporal trends in unemployment across India.
