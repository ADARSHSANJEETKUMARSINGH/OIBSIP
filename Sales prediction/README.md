# 📊 Sales Prediction using Machine Learning

## 🚀 Project Overview

This project predicts product sales based on advertising expenditure across different platforms such as TV, Radio, and Newspaper.

A **Linear Regression model** is used to understand how advertising budgets influence sales and to make accurate predictions.

## 🧠 Problem Statement

Businesses need to estimate future sales based on advertising spending.

This project predicts **Sales** using:

* TV Advertising Budget
* Radio Advertising Budget
* Newspaper Advertising Budget

---

## 📊 Model Performance

* **MAE:** 1.46
* **MSE:** 3.17
* **R² Score:** 0.90

👉 The model explains ~90% of the variance in sales.

---

## 💡 Business Insight

* 📈 **TV Advertising:** Strong impact on sales
* 📻 **Radio Advertising:** Moderate impact
* 📰 **Newspaper Advertising:** Minimal impact
