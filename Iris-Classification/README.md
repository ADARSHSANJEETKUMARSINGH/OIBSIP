🌸 Iris Flower Classification

This project is part of my Oasis Infobyte Data Science Internship (OIBSIP).

In this project, I worked on the famous Iris dataset to classify flowers into three different species based on their physical features like sepal length, sepal width, petal length, and petal width.

📊 About the Dataset

The dataset contains 150 samples of iris flowers divided into three classes:

* Setosa
* Versicolor
* Virginica

Each sample includes four numerical features which are used to predict the species of the flower.

⚙️ What I Did

* Loaded and explored the dataset
* Performed basic data analysis and visualization
* Handled preprocessing (label encoding, cleaning)
* Split the data into training and testing sets
* Trained a Logistic Regression model
* Evaluated the model using accuracy, classification report, and confusion matrix

🤖 Model Used

* Logistic Regression

📈 Results

The model achieved high accuracy on the test data and performed well across all classes.
